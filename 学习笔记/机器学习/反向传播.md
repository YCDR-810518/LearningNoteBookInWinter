# 反向传播

  **这个算法是从结果反推回来调整原来的参数**

借助的**结果**是**损失函数**，通过loss函数中的Y值作为纽带，用链式法则回推偏导数

----

## 具体的解释&详细过程

![截屏2026-03-16 20.57.05](https://raw.githubusercontent.com/YCDR-810518/imageBed/main/picGo/截屏2026-03-16 20.57.05.png)

可以看到损失函数中的**y**与y=wx+b中的**y**是**同一个y**

----

下面是对于上面这种单神经元的求法的详细

### 操作步骤（其实就是间接地求偏导数）

1. 对损失函数求导
2. 对y = wx+b求导
3. 把上面求导的两个相乘（此时就求得了斜率）（在多个参数时为曲率）
4. 将曲率与学习率相乘（这个是梯度）
5. 将原来的参数减去该梯度即可让参数在优化平面下移
6. 反复以上5步，就是训练

### 程序的实现

上面的操作步骤，对应的是numpy中的loss.backward()

下面是Gemini给出的参考代码

```python
import numpy as np

# 1. 初始化输入和参数 (对应图片底部的数值)
x = 1.5
w = 0.8
b = 0.2
y_gt = 0.8

# 2. 前向传播 (Forward Pass)
y = w * x + b
loss = 0.5 * (y - y_gt)**2

print(f"前向传播结果:")
print(f"预测值 y: {y:.2f}")
print(f"损失值 L: {loss:.4f}\n")

# 3. 反向传播 (Backward Pass) - 对应图片中的链式法则
# 第一步: 求 loss 对 y 的偏导 (dL/dy)
dy = y - y_gt

# 第二步: 求 loss 对 w 和 b 的偏导
dw = dy * x  # (y - y_gt) * x
db = dy * 1  # (y - y_gt) * 1

print(f"反向传播梯度:")
print(f"dL/dy (中间梯度): {dy:.2f}")
print(f"dL/dw (权重梯度): {dw:.2f}")
print(f"dL/db (偏置梯度): {db:.2f}")

# 4. 模拟一步参数更新 (假设学习率 lr = 0.1)
lr = 0.1
w_new = w - lr * dw
b_new = b - lr * db

print(f"\n更新后的参数:")
print(f"w_new: {w_new:.4f}, b_new: {b_new:.4f}")
```

```py
import torch
import torch.nn as nn
import torch.optim as optim

# 1. 准备环境
# 目标：让 w=0.8, b=0.2
# 初始：随机设定，让模型去“猜”
x = torch.tensor([1.5])
y_gt = torch.tensor([0.8]) # 0.8 * 1.5 + 0.2 = 1.4，这里我们让 y_gt = 1.4

model = nn.Linear(1, 1) # 自动包含 w 和 b，初始值为随机数
optimizer = optim.SGD(model.parameters(), lr=0.1) # 学习率为 0.1
criterion = nn.MSELoss() # 均方误差损失函数

# 2. 训练循环 (让它迈 50 次步子)
print(f"初始状态: w={model.weight.item():.4f}, b={model.bias.item():.4f}")

for step in range(50):
    optimizer.zero_grad()      # 1. 清空梯度
    y_pred = model(x)          # 2. 前向传播
    loss = criterion(y_pred, y_gt) # 3. 计算损失
    loss.backward()            # 4. 反向传播 (链式法则)
    optimizer.step()           # 5. 更新参数 (迈出一步)
    
    if (step + 1) % 10 == 0:
        print(f"第 {step+1:02d} 步: Loss={loss.item():.4f}, w={model.weight.item():.4f}, b={model.bias.item():.4f}")
```

```python
import torch
import torch.nn as nn

class MyCustomNeuron(nn.Module):
    def __init__(self):
        super(MyCustomNeuron, self).__init__()
        # 手动定义参数，明确告知 PyTorch 需要求导
        self.w = nn.Parameter(torch.randn(1, requires_grad=True))
        self.b = nn.Parameter(torch.randn(1, requires_grad=True))

    def forward(self, x):
        # 这一步就是你完全自定义的计算逻辑
        # 只要符合数学运算，你可以写任何复杂的逻辑
        y = self.w * x + self.b
        return y

# 使用方法：
model = MyCustomNeuron()
output = model(1.5) # 自动调用了上面的 forward 函数
```
