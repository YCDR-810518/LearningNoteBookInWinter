# 逻辑回归

**逻辑回归（Logistic Regression）**名字里虽然有**“回归”**二字，但它本质上是用来解决**分类问题**的

## 相同点

**线性基石**：逻辑回归的内部仍然是一个线性函数 
$$
z = w^Tx + b 
$$
关于线性回归相关具体内容可以参见[线性回归笔记](https://github.com/YCDR-810518/LearningNoteBookInWinter/blob/main/%E5%AD%A6%E4%B9%A0%E7%AC%94%E8%AE%B0/%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0/%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92.md)

**目的**：两者都是为了寻找最合适的参数 w 和 b，使得模型能够最好地拟合数据特征。

## 不同点

| **维度**     | **线性回归 (Linear Regression)**                 | **逻辑回归 (Logistic Regression)**                           |
| ------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| **任务类型** | **回归**：预测连续数值（如房价、气温）。         | **分类**：预测离散标签（如是否为垃圾邮件、是猫还是狗）。     |
| **输出范围** | **无限制**：输出可以是实数域范围。               | **有限制**：输出在 (0, 1) 之间，表示概率。                   |
| **映射函数** | 直接输出线性组合结果 y = w^Tx + b。              | 使用 **Sigmoid 函数** 将线性结果映射到 0-1 之间。            |
| **损失函数** | **均方误差 (MSE)**：即你笔记中提到的最小二乘法。 | **交叉熵损失 (Cross-Entropy)**：衡量预测概率与真实标签的差异。 |

### 逻辑回归的“魔法”：Sigmoid 函数

在笔记的线性公式基础上，逻辑回归多了一步转化：

$$
y = \frac{1}{1 + e^{-(w^Tx + b)}}
$$
这个函数将线性函数压缩为了一个**[0, 1]**区间上的**概率**
