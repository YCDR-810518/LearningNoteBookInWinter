# 数据预处理

## 标准化standardization

 **Z-score（标准分数）公式**

这个东西将根据正态分布的数据转换到标准正态分布下
$$
z = \frac{x - \mu}{\sigma}
$$ {0}

## 归一化(normalization)

### 归一化公式（Min-Max Scaling）

$$
x_{norm} = \frac{x - x_{min}}{x_{max} - x_{min}}
$$

结果：最小值会被映射为 **0**，最大值会被映射为 **1**，其余数值均匀地分布在中间

## 对比

| **特性**     | **归一化 (Min-Max)**                   | **标准化 (Z-score)**                 |
| ------------ | -------------------------------------- | ------------------------------------ |
| **映射区间** | 严格在 **[0, 1]** 之间                 | 无固定区间（均值为 0，标准差为 1）   |
| **分布形状** | 改变分布压缩比例，不改变相对位置       | **不改变**原始分布形态（依然是正态） |
| **对异常值** | **极其敏感**（一个极值会压缩所有数据） | 比较稳健（受极值影响较小）           |
| **适用场景** | 图像处理、神经网络（需固定范围）       | 统计分析、分类算法（如 SVM, KNN）    |

## 运用

在训练&使用时要注意：

在测试集进行归一化时，要用训练集的均值，标准差，最大/最小值

### 数据预处理的流程图

| **步骤**              | **动作**                          | **核心目标**                       |
| --------------------- | --------------------------------- | ---------------------------------- |
| **一、审视**          | 描述性统计（Mean, Std, Min, Max） | 建立全局观，发现初步反常。         |
| **二、处理缺失**      | 填充或删除                        | 保持样本的代表性。                 |
| **三、剔除/保留异常** | 盖帽法或单独标记                  | 区分噪声与新规律。                 |
| **四、转换**          | 归一化/标准化/对数变换            | 消除量纲影响，使数据服从特定分布。 |
| **五、验证**          | 逻辑检查                          | 确保数据符合现实常识。             |
