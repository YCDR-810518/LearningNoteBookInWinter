# 面试的相关准备

## 有待复习的内容

## 1. 神经网络底层（对应你的 NumPy 实践）

面试官可能会通过你的代码来挖掘你对“黑盒”内部的理解：

- **激活函数的作用**：为什么要引入 Sigmoid 或 ReLU？如果不加激活函数，多层神经网络会变成什么？
- **反向传播的直观理解**：你是如何利用链式法则计算权重的梯度的？ 既然你手写过神经网络，面试官可能会问你：当梯度消失时，网络会有什么表现？
- **归一化的必要性**：你之前处理过降雨预测数据，为什么要将输入数据缩放到 0-1 之间？不缩放会影响梯度下降的速度吗？

## 2. 数学与算法逻辑（对应 Day10-17）

即使不刷人，QG 也很看重你对公式背后“物理意义”的思考：

- **梯度下降的参数选择**：学习率（Learning Rate）设得太大或太小分别会发生什么？
- **过拟合（Overfitting）**：你怎么判断模型是“学到了规律”还是“背下了答案”？
- **线性回归与解析解**：除了梯度下降，为什么矩阵运算（最小二乘法）也能求出最优解？

## 3. 工程素养与工具链（你的强项）

这部分最能体现你作为一个“准专业开发者”的性格：

- **代码规范**：你如何理解“代码是给人看的”？在你的 Python 实践中，你是如何通过类（Class）和封装来提高代码可读性的？
- **Git 协作流程**：如果你和队友修改了同一个文件导致冲突（Conflict），你会如何处理？
- **环境管理**：既然你推崇 **uv**，你能说出它相比于传统 pip 或 conda 的具体优势吗？（比如多平台锁定、极致的安装速度）
