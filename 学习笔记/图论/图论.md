# 图论

## 定义

**图**(Graph)是由**顶点**的有穷非空集合**V(G)**和顶点之间**边**的集合**E(G)**组成。

* 顶点V(G)：实际上就是节点的集合，如同一个一个人
* 边E(G)：就是节点和节点之间的联系的集合，人与人之间的联系

用｜V｜表示图G中的顶点个数，即**图G的阶**

用｜E｜表示图G中**边的条数**

## 有向图 (Directed Graph)：单向或有序的关系

在有向图中，边（也叫“弧”）有箭头，表示从一个点指向另一个点。方向不同，含义完全不同。

- **形象比喻：微博/抖音关注**
  - 你可以关注一个大 V（你指向他），但大 V 不一定关注你。
  - 如果 A 关注了 B，记作 `<A, B>`。A 是**弧尾**（发出者），B 是**弧头**（接收者）。
  - <v,w>称为从顶点v到顶点w的弧，也称**v邻接到w**，或**w邻接自v**

## 无向图 (Undirected Graph)：对等的关系

在无向图中，边没有方向。如果点 A 和点 B 之间有一条边，表示 A 到 B 和 B 到 A 是完全等价的。

- **形象比喻：微信好友 / 握手**
  - 如果你和某人是微信好友，那么这种关系是**双向**的，你是他的好友，他也是你的好友。
  - **数学表达：** (v,w)=(w,v)。圆括号表示这是个“**无序对**”，谁写在前面都一样。

| **特性**         | **无向图 (Undirected)**        | **有向图 (Directed)**              |
| ---------------- | ------------------------------ | ---------------------------------- |
| **边的名称**     | 边 (Edge)                      | 弧 (Arc)                           |
| **符号表示**     | 圆括号 $(v, w)$                | 尖括号 $<v, w>$                    |
| **关系性质**     | 对称、双向                     | 非对称、单向（除非有两条相反的弧） |
| **形象理解**     | 微信好友、电话通话、普通双向路 | 关注、汇款、单行道、网页链接       |
| **数据结构含义** | 邻接矩阵是对称的               | 邻接矩阵通常是不对称的             |

## 加权图

一个图中，每条边都可以标上具有某种含义的**数值**，该数值称为该边的**权值**。

**普通图（无权图）：** 只告诉你从 A 城市到 B 城市有路。

**加权图：** 不仅告诉你两地有路，还明确标注了这条路**有多长**（距离）、**开过去要多久**（时间），或者**过路费要多少**（金钱）。

### 典例

**社交网络中的亲密度：**

- 虽然你和很多人都是好友，但你和死党每天聊天（权重 = 100），和点头之交一年说一句（权重 = 1）。权重代表了**关系的紧密程度**。

**神经网络（AI）：**

- 神经元之间的连接权重。权重越大，信号传递的效果越强。这就是 AI 模型训练时反复调整的那个“参数”。

### 作用

在计算机科学里，加权图是**优化问题**的核心。

- **Dijkstra 算法：** 寻找加权图中两点间总权重最小的路径（比如找最便宜的机票组合）。
- **最小生成树：** 假如你要给 5 个村庄通电，如何用最短的总电缆把它们全部连通？（降低建设成本）。<img src="https://raw.githubusercontent.com/YCDR-810518/imageBed/main/picGo/image-20260320111100788.png" alt="image-20260320111100788" style="zoom:50%;" />

## 邻接矩阵

### 无向图

<img src="https://raw.githubusercontent.com/YCDR-810518/imageBed/main/picGo/image-20260320112426695.png" alt="image-20260320112426695" style="zoom:50%;" />

### 形象理解：Excel 查期表

你可以把右边的矩阵想象成一张**城市直达航班表**：

- **横行（Row）**：代表“出发地”。
- **纵列（Column）**：代表“目的地”。
- **格子里的数字**：
  - **1**：表示这两个城市之间有路（或有航班）。
  - **0**：表示没有直接相连的路。

### 邻接矩阵图的解释

#### ① 顶点数组 (Vertex Array)

就是图上方那个一维数组 `[v0, v1, v2, v3]`。它像是一个**花名册**，记录了图中所有成员的名字。计算机通过下标（0, 1, 2, 3）来快速定位每一个点。

#### ② 边数组 / 邻接矩阵 (Edge Array)

这是核心。请注意观察几个特征：

- **主对角线全为 0**：从左上角到右下角的斜线（0,0; 1,1...）都是 0（因为是自己到自己）
  - 形象理解：通常我们不考虑“自己到自己”的有意义连接（除非有自环）。
- **对称性**：你会发现矩阵沿主对角线“对折”是一模一样的。这说明它是一个**无向图**。如果 v0 到 v1 有路（值为 1），那么 v1 到 v0 必然也有路（值为 1）。

**度的计算**：

- 图中圈出的 v1 那一行：`1 0 1 0`。
- 把这一行（或这一列）的数字加起来，1+0+1+0=2。
- **结论**：v1 的“度”是 2，代表它有 2 个邻居。看左边的图，v1 确实只连了 v0 和 v2。

## 优缺点直觉

- **优点（快）**：你想知道 v0 和 v3 认识吗？直接查 `matrix[0][3]`，一眼出结果。
- **缺点（费钱/空间）**：如果一个图有 10,000 个顶点，但每个点只连了 1 个人（非常稀疏），你依然要建一个 10,000×10,000 的大表，里面全是 0，非常浪费内存。

### 有向图

<img src="https://raw.githubusercontent.com/YCDR-810518/imageBed/main/picGo/image-20260320113425537.png" alt="image-20260320113425537" style="zoom:50%;" />

**所有的连接都有箭头**：

- **单向连接**：比如 v0→v3，这很明确。
- **双向连接**：比如 v1 和 v2 之间，它们看似是“连通”了，但在有向图中，这实际上是**两条独立的弧**：一条是 <v1,v2>，另一条是 <v2,v1>。

## 形象理解：入度 vs 出度

这张图引入了两个非常关键的“有向图专属”概念：

- **出度 (Out-degree)**：从这个点**发出去**的箭头数量。
  - 看矩阵的**行**。比如 v1 这一行是 `1 0 1 0`，加起来是 2。说明 v1 指向了两个人。
- **入度 (In-degree)**：**指向**这个点的箭头数量。
  - 看矩阵的**列**。比如 v1 这一列是 `0 0 1 0`，加起来是 1。说明只有一个人指向 v1。

> **生活形象化**： 在社交媒体（有向图）里，**出度**是你关注的人数，**入度**是你的粉丝数。
>
> - v3 在图中只有入度（1），没有出度（0），它就像是一个**纯听众**或者**僵尸号**。
> - v0 很有趣，它关注了 v3（出度），但 v3 没理它。

## 如果变成“加权图”会怎样？

<img src="https://raw.githubusercontent.com/YCDR-810518/imageBed/main/picGo/image-20260320113616495.png" alt="image-20260320113616495" style="zoom:50%;" />

如果是加权图，矩阵里的 **1** 就会变成具体的**数字（权重）**。

- 比如 v0 到 v1 距离 5 公里，格子里的 `1` 就会变成 `5`。
- 如果没有路，通常会用一个很大的数（无穷大 ∞）来表示，因为“0”可能代表距离是 0。
