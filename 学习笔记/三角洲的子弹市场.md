## 数据处理所需收集的数据

### 子弹表

| **字段名**          | **类型** | **说明**                                                     |
| ------------------- | -------- | ------------------------------------------------------------ |
| 记录时间            | datetime | 记录时间（建议用 `pd.to_datetime` 处理）                     |
| 子弹名称            | string   | 子弹名称（如：5.56mm M855A1）                                |
| 子弹等级            | int      | 等级0~5                                                      |

### 1. 单发净利 (Net Profit per Bullet)

这是所有计算的基石。它代表你卖出一发子弹，扣除所有成本和税后，实打实进兜里的钱。

![image-20260224211010843](https://raw.githubusercontent.com/YCDR-810518/imageBed/main/2026/02/upgit_20260224_1771938610.png)

- **市场售价：** 你录入的交易行价格。
- **税率 (13.2%)：** 包含上架费和交易手续费。
- **单发成本：** 这一炉所有材料的总价/产出数量。

### 2. 一炉总利 (Total Batch Profit)

这是你这 8 小时挂机下来，这一个坑位能带给你的总收益。

![image-20260224211109299](https://raw.githubusercontent.com/YCDR-810518/imageBed/main/2026/02/upgit_20260224_1771938669.png)

- **意义：** 帮你判断这个“配方”值不值得占一个工作台坑位。

### 3. 时效 (/h) (Profit per Hour)

**这是倒爷最关键的指标。** 因为工作台的坑位和时间是有限的资源。

![image-20260224211130344](https://raw.githubusercontent.com/YCDR-810518/imageBed/main/2026/02/upgit_20260224_1771938690.png)

- **案例对比：**
  - **子弹 A**：一炉赚 8000，要搓 8 小时，时效 = **1000/h**。
  - **子弹 B**：一炉赚 6000，只需 5 小时，时效 = **1200/h**。
- **结论：** 即使子弹 B 总利润低，但它的时效更高，你应该优先搓子弹 B，这样你一整天赚的钱更多。

### 4. ROI (投资回报率)

衡量你投入的哈夫克币“生钱”的效率。

![image-20260224211146934](https://raw.githubusercontent.com/YCDR-810518/imageBed/main/2026/02/upgit_20260224_1771938706.png)

- **意义：** 帮你判断风险。如果 ROI 只有 5%，说明只要原材料涨价一点点，你就会亏本。通常 ROI **超过 20%** 才是比较稳的生意。
