# 面向对象编程
## 类(class)与实例化(instantiation)
**类**：是一类变量的总称，即水果之于苹果，包含了水果功能的定义
**实例化**：根据类，创建具体的实例，即用类定义创建出一个真正的水果
代码：
```Python
#创建类
class Robot:
	pass

#实例化
robot1 = Robot()
```
## 类变量&实例变量
**类变量**：所有在这个类下创建的实例都会拥有的信息
**实例变量**：每个实例独有的信息，如苹果的编号，产地
```python
class Robot:
    factory = "CyberLife"  # 类变量：所有机器人共有

    def __init__(self, name):
        self.name = name   # 实例变量：每个机器人名字不同
```
### 实例变量的创建相关语法原理
**def __init__(self, name):**
**def __init__** 这里是一个初始化方法
**self** 代指正在被创建的实例自己
**name** 传入的参数，仅在__init__函数内部有效

---
### 实例变量定义公式
self.name = name
* 左侧的**self.name**是真正的实例变量（挂在了self身上），跟着对象走，可以在类的其他地方使用
* 右边的**name**是一个临时的参数名称
eg:
```python
class Car:
	def __init__(self,brand,price):
		self.brand = brand
		self.price = price
		self.is_running = False
```
---
### 放在类里面的函数种类
1. **实例方法**（instance Method）
* **特点**：第一个参数必须是self
* **作用**：对具体对象进行操作
* **例子**：```car1.drive()```仅有car1在跑

---
2. **类方法 (Class Method) —— 针对整个“型号”**
* 语法：使用装饰器 @classmethod，第一个参数通常叫 cls（代表 Class 本身）。
* 作用：处理和整个类相关的数据，而不是某个具体的车。
* 例子：统计“工厂一共造了多少辆车”。
---
3. **静态方法 (Static Method) —— 纯工具函数**
* 语法：使用装饰器 @staticmethod，不需要 self 也不需要 cls。
* 作用：它只是碰巧放在这个类里的一个普通函数，不依赖类或实例的状态。
```python
class Car:
    total_cars = 0  # 这是一个“类变量”，全厂共有

    def __init__(self, brand):
        self.brand = brand
        Car.total_cars += 1  # 每造一辆车，总数加1
        
    # 1. 实例方法：操作具体的车
    def start_engine(self):
        print(f"{self.brand} 的引擎启动了！")

    # 2. 类方法：操作全厂数据
    @classmethod
    def show_factory_stats(cls):
        print(f"工厂目前共制造了 {cls.total_cars} 辆车。")

    # 3. 静态方法：纯逻辑判断
    @staticmethod
    def is_motorway_safe(speed):
        return speed <= 120
```
## 私有化变量&封装
1. 私有化的介绍
* 目的：让用户通过接口（特定函数）进行间接的操作，不让其直接操作变量
* **语法**：在名字前加两个下划线__
* **例子：**
```python
class BankAccount:
    def __init__(self, owner, money):
        self.owner = owner          # 公开变量
        self.__balance = money      # 私有变量：外部不能直接访问

    def __check_id(self):           # 私有方法：内部逻辑校验
        print("正在核验身份...")
        return True

    def withdraw(self, amount):     # 公开方法：对外提供的接口
        if self.__check_id():       # 内部可以调用私有方法和变量
            self.__balance -= amount
            print(f"取款成功，余下 {self.__balance}")
```
---
2. 尝试访问的结果
```python
acc = BankAccount("小王", 1000)

print(acc.owner)       # 正常输出：小王
print(acc.__balance)   # 报错！AttributeError: 'BankAccount' object has no attribute '__balance'
acc.__check_id()       # 报错！AttributeError
```
3. 关于**伪私有**
Python 并没有真正把这些变量锁死，它只是偷偷改了名字，这种机制叫 名称修饰 (Name Mangling)。

* __balance 实际上被改成了：_类名__变量名（即``` _BankAccount__balance```）。
* 如果你非要作死，执行 ```print(acc._BankAccount__balance)```，它是能访问到的。

4. 单下划线 `_` 又是啥？

你可能还会看到 `_name`（只有一个下划线）。

- **含义**：这只是一个“视觉警告”，告诉其他程序员：“这是一个内部变量，虽然你可以访问，但请尽量别动它。”
- **区别**：它不会像双下划线那样被改名，它更多是一种**社交规范**。

| **语法** | **类型**           | **外部访问**              | **建议用途**                   |
| -------- | ------------------ | ------------------------- | ------------------------------ |
| `name`   | 公开 (Public)      | 随意                      | 正常的数据和接口               |
| `_name`  | 受保护 (Protected) | 可以，但不建议            | 仅限类内部或子类使用           |
| `__name` | 私有 (Private)     | **报错** (除非用特殊手段) | 核心机密、不想被子类覆盖的逻辑 |

## 继承（inheritance）

允许创建一个类（**子类**），使其自动拥有另一个类（**父类/基类**）的所有属性和方法

**语法：** `class 子类名(父类名):`

```python
# 父类 (Base Class)
class Vehicle:
    def __init__(self, brand):
        self.brand = brand

    def move(self):
        print(f"{self.brand} 正在移动...")

# 子类 (Derived Class)
class ElectricCar(Vehicle): # 继承自 Vehicle
    def __init__(self, brand, battery_size):
        # 使用 super() 调用父类的 __init__，避免重复写代码
        super().__init__(brand) 
        self.battery_size = battery_size

    def charge(self):
        print(f"{self.brand} 正在充电，容量为 {self.battery_size}kWh")
```

**super()**的作用就是让python用父类的初始化逻辑进行赋值操作

## 多态(Polymorphism)**和而不同**

不同的对象对同一个方法名（函数名）有不同的实现方式

即**方法重写**(Method Overriding)

```python
class GasolineCar(Vehicle):
    def move(self): # 重写父类的 move 方法
        print(f"{self.brand} 轰鸣着发动了发动机！")

class Bicycle(Vehicle):
    def move(self): # 同样是 move，实现不同
        print(f"{self.brand} 链条沙沙作响，全靠腿蹬。")

# --- 多态的魅力体现在这里 ---
def start_journey(v):
    v.move() # 无论传进来的是什么车，我都只管调用 .move()

car1 = GasolineCar("法拉利")
bike1 = Bicycle("捷安特")

start_journey(car1)  # 输出：法拉利 轰鸣着...
start_journey(bike1) # 输出：捷安特 链条沙沙...
```

- **继承** 解决了“**懒**”的问题：不用重复写品牌、价格等通用属性。
- **多态** 解决了“**通用**”的问题：你的主程序（比如上面的 `start_journey` 函数）不需要知道对方具体是什么车，只要它是 `Vehicle` 的子类，拥有 `move` 方法，程序就能跑通。
