### 1. `flatten()`：最稳妥的复制

`flatten()` 会返回原数组的一个**副本**。这意味着如果你修改了展平后的数组，原数组**不会**受到影响。

- **特点**：安全，但因为涉及内存复制，处理超大数组时速度略慢。
- **用法**：`flat_arr = arr.flatten()`

### 2. `ravel()`：最高效的“视图”

`ravel()` 通常返回原数组的一个**视图**（View）。这意味着它不复制数据，而是改变查看数据的方式。

- **特点**：速度极快，节省内存。
- **警告**：由于是视图，如果你修改了 `ravel()` 后的数组，**原数组也会被修改**。
- **用法**：`view_arr = arr.ravel()`

### 3. `reshape(-1)`：最灵活的变形

利用 `reshape` 函数，将维度设置为 `-1`，NumPy 会自动计算该维度的长度，从而达到展平的效果。

- **特点**：效果与 `ravel()` 类似，通常返回视图。
- **用法**：`reshaped_arr = arr.reshape(-1)`

------

### 🎨 核心差异对比

| **方法**          | **返回类型** | **修改新数组是否影响原数组** |
| ----------------- | ------------ | ---------------------------- |
| **`flatten()`**   | 副本 (Copy)  | ❌ 不影响                     |
| **`ravel()`**     | 视图 (View)  | ✅ 会影响                     |
| **`reshape(-1)`** | 视图 (View)  | ✅ 会影响                     |

### 💡 进阶小贴士：展平的顺序

默认情况下，展平是按**行**进行的（C-style，C语言风格）。如果你想按**列**展平，可以添加参数 `order='F'`（Fortran风格）：

Python

```
import numpy as np
arr = np.array([[1, 2], [3, 4]])

# 默认行展平: [1, 2, 3, 4]
# 列展平 (order='F'): [1, 3, 2, 4]
print(arr.flatten(order='F'))
```
