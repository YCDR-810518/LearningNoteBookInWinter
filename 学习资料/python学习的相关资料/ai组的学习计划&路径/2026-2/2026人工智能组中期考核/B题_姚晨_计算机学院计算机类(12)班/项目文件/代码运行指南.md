# 代码运行指南
## 环境
* 该项目环境是由uv搭建的,**我建议使用uv**来搭建环境
  * uv的**环境初始化命令**
    * `uv sync`
    * 该命令会自动使用uv.lock安装相应的包和环境
* 同时,我还提供了其他的环境初始化方法
  * `requiremts_uv.txt`
    * 提供了基于uv的现代requirement.txt
    * 使用时请**一定记得**将其**改名**为requirement.txt,并**删除**另一个requirement.txt文件
    * **环境初始化命令**
      * `uv pip freeze > requirements.txt`
  * `requirement.txt`
    * 不依赖于uv,原生pip即可激活
    * **环境初始化命令**
      * `pip install -r requirements.txt`
### 注意!需要通过包管理器下载ffmpeg用于生成MP4文件
  * Windows用chocolatey 下载 `choco install ffmpeg`
  * mac/Linux用homebrew 下载即可 `brew install ffmpeg`
