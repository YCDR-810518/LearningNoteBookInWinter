# 基于前缀树的差分隐私研究论文笔记

## 相关的模型及解释

### 查询概率模型

1. 随机查询，每个位置在每次被查询的概率相等
2. 查询是有放回的（即轨迹不会成环）
3. 由(1)，查询之间没有相关性，可以视为独立事件

* 根据假设 1，查询中的第一个位置有 $|\mathcal{L}|$ 种可能性

* 剩余查询中的每个位置将有 $|\mathcal{L}| - 1$ 种可能性
  * $N_l = |\mathcal{L}| * (|\mathcal{L}| - 1) * (|\mathcal{L}| - 1) * \dots * (|\mathcal{L}| - 1) = |\mathcal{L}| * (|\mathcal{L}| - 1)^{l-1} \quad (2)$
  
* 对于长度为L的轨迹，其查询总数的方程为下面的方程
  * $$N = \sum_{l=l_{min}}^{l_{max}} N_l = \frac{|\mathcal{L}| * (|\mathcal{L}| - 1)^{l_{min}-1} [(|\mathcal{L}| - 1)^{l_{max}-l_{min}+1} - 1]}{|\mathcal{L}| - 2} \quad (3)$$
  
* 接下来是自底向上推断查询的概率

  * 首先检查与叶节点相关的轨迹，即长度最长的轨迹 $l = l_{max}$

  * 故叶节点的查询概率可以用下面的公式表示

    * $$p_{leaf} = \frac{1}{N} = \frac{|\mathcal{L}| - 2}{|\mathcal{L}| * (|\mathcal{L}| - 1)^{l_{min}-1} [(|\mathcal{L}| - 1)^{l_{max}-l_{min}+1} - 1]} \quad (4)$$

  * 往上一层之后，父节点的概率是其本身加上所有子节点之和，即下面的公式

    * $$p_i = p_{itself} + k * p_{child} = 1/N + k/N \quad (5)$$

  * 故所有节点的查询概率可以以下面的公式表示

    * $$p_i = p_{itself} + \sum_{j \in child(i)} p_j = 1/N + \sum_{j \in child(i)} p_j \quad (6)$$
    * > 解释：
      >
      > 这是整个模型的基础。一个父节点被“查询”到，意味着它的孩子节点也被“查询”到了，因为父节点是孩子节点的“前缀”。所以父节点的总查询概率就是“自身直接被命中”的概率加上所有孩子被命中的概率之和




### 最优隐私预算分配算法（拉格朗日松弛法）

设 $X$ 服从拉普拉斯分布，$X \sim Laplace(\mu, b)$，则 $X$ 的概率密度函数为：

* $$f(x|\mu, b) = \frac{1}{2b} e^{-\frac{|x-\mu|}{b}} \quad (7)$$

由于该节点被查询的概率为 $p_i$，所以添加噪声后的总查询误差期望可以表示为下列公式，要让公式（9）最小化

* $$minimize f(\epsilon_i) = \sum_i E(Err(i))/2 = \sum_i p_i/\epsilon_i^2 \quad (8)$$
* $$\sum_{i \in path(root, j)} \epsilon_i = \epsilon \quad \forall j \in leaf \quad (9)$$

故每一条线的路径的总预算都为$$\epsilon$$

* $$\epsilon_G + \epsilon_B + \epsilon_A = \epsilon$$

  $$\epsilon_N + \epsilon_H + \epsilon_C + \epsilon_A = \epsilon$$

  $$\dots$$

  $$\epsilon_M + \epsilon_F + \epsilon_A = \epsilon \quad (10)$$

> 这里的目标是**最小化所有节点的查询误差总和**。
>
> 每个节点的误差贡献由两部分组成：$p_i$（被查询的频率，权重）和 $1/\epsilon_i^2$（添加噪声导致的方差项，即隐私带来的代价）。
>
> 这是一个经典的凸优化问题：如何在满足线性约束（预算和为 $\epsilon$）的前提下，调整 $\epsilon_i$ 使得 $\sum p_i / \epsilon_i^2$ 最小。
* 所有的约束条件：
  *  $$minimize \quad f(\epsilon_i) = \sum_i \frac{p_i}{\epsilon_i^2}$$
    
  *  $$s.t. \quad \sum_{i \in path(root, j)} \epsilon_i = \epsilon \quad \forall j \in leaf$$
  *  $$p_i = \frac{1}{N} + \sum_{j \in child(i)} p_j$$
  *  $$p_{leaf} = \frac{|\mathcal{L}| - 2}{|\mathcal{L}| * (|\mathcal{L}| - 1)^{l_{min}-1} [(|\mathcal{L}| - 1)^{l_{max}-l_{min}+1} - 1]} \quad (11)$$

此处省略了一大堆的计算推导过程...

在最后可以推出下列式子

* 对于叶节点
  * $$\frac{dL(\epsilon_i)}{d\epsilon_i} = -2 * \frac{p_i}{\epsilon_i^3} + \lambda_i = 0 \quad (13)$$
* 对于非叶节点
  * $$\frac{p_i}{\epsilon_i^3} = \sum_{a \in [1, k]} \frac{1}{2}\lambda_a = \sum_{a \in [1, k]} \frac{p_{childleaf_{ia}}}{\epsilon_{childleaf_{ia}}^3} \quad (23)$$

> 此处给出一些解释
>
> **拉格朗日松弛法的应用 (Eq. 12)**：
>
> - 原始问题是“带有路径约束的最小化”，这很难直接求导。
> - 通过引入**拉格朗日乘子 $\lambda$**，将约束条件 $\sum \epsilon = \epsilon$ “惩罚”项加入目标函数中，转换成了无约束优化问题。这使得我们可以利用微积分（对 $\epsilon_i$ 求偏导）来寻找最小值点。
>
> **导数意义 (Eq. 13 & 15)**：
>
> - 令导数等于 0 是寻找函数极值点的标准步骤。
> - 这里的直观含义是：在最优预算分配下，每个节点的“边际效用”（对减少误差的贡献）与它的隐私成本（由 $\lambda$ 反映的某种 Lagrange 乘子平衡）达到了均衡。
>
> **命题 1-3 的意义**：
>
> - 这些命题简化了计算复杂度。例如，命题 2 指出兄弟叶节点必须平分预算，命题 3 给出了非叶节点与其所有后代叶节点之间预算的递推关系。
> - 这意味着我们不需要同时解成百上千个复杂的方程组，而是可以根据这些性质，通过自顶向下或自底向上的递归算法来高效求解最优解。这正是该模型实现“高效”的关键所在。

## 相关的公式及解释

### 相对误差数学公式

$relative_{error} = |q(\widehat{D}) - q(D)| / \max(q(D), s)$

**用途**：是用来定量测量所开发算法对轨迹数据集的影响

> 具体可以看fig3-7的内容，被用来和其他几个基线算法做比较

**解释**：

* $q$ 是一个计数查询函数，返回轨迹数据集中子轨迹的数量
* $q(D)$ 是原始数据集 D 的计数查询结果
* $q(\widehat{D})$ 代表脱敏数据集 $\widehat{D}$ 的计数查询结果
* 方程中的 $s$ 代表理性界（sanity bound）
* 通常在许多差分隐私研究中被设为数据集的 0.1% （为了防止epsilon过小击穿下限，让误差起飞）

### 主要具体的程序运行过程（伪代码）

**算法 1 主函数**

输入：原始交通轨迹 $D$

输入：前缀树高度 $h$

输入：可用的总隐私预算 $\epsilon$

输入：阈值参数 $k, b$

输出：脱敏轨迹数据集 $\widehat{D}$

1. 扫描一次 $D$ 以构建 $PT$ 并用树结构存储 $D$；
2. $PT \leftarrow BudgetAllocation(PT, \epsilon)$
3. 从树层级 $lv=1$ 的根节点开始；
4. 当 $lv \le h$ 时：
5. 计算层级 $lv$ 的隐私阈值，$\theta_{lv} = k \times (lv)^{-1} + b$；
6. 对于 $PT$ 中层级 $lv$ 的每个节点 $i$：
7. $i.count += Lap(1/\epsilon_i)$
8. $BuildChildTree(i, \epsilon_i, c_i, \theta_{lv})$；
9. 结束循环
10. $lv++$；
11. 结束循环
12. $\widehat{D} \leftarrow Output(PT)$; 返回 $\widehat{D}$。

**过程 1 BudgetAllocation**

输入：前缀树根节点 $PT$，总预算 $\epsilon$

输出：具有优化预算 $\epsilon_i$ 的脱敏前缀树 $PT'$

1. 函数 Allocate ($i$)
2. 如果 $i$ 是叶节点，则
3. $\epsilon_i = \epsilon$
4. 跳出
5. 否则
6. 对于 $i$ 的每个子节点 $j$，执行
7. Allocate ($j$)
8. 结束循环
9. $sum = 0$
10. 对于从节点 $i$ 衍生的每个叶节点 $leaf_i$，执行
11. $sum += \epsilon / \epsilon_{leaf_i}^3$
12. 结束循环
13. $\epsilon_i = i.(children_{count} / sum^{\frac{1}{3}})$
14. Normalize ($i, \epsilon_i / \epsilon + 1$)
15. 结束循环
16. 结束函数
17. 函数 Normalize ($i, coef$)
18. $\epsilon_i \neq coef$
19. 如果 $i$ 不是叶节点，则：
20. 对于 $i$ 的每个子节点 $j$，执行
21. Normalize ($j, coef$)
22. 结束循环
23. 结束判断
24. 结束函数
25. 从 $PT$ 的根节点开始预算分配：Allocate (root)

**过程 2 BuildChildTree**

输入：父节点 $i$，位置 $l_i$，时间 $t_i$；阈值 $\theta_{lv}$，隐私预算 $\epsilon_i$，带噪计数 $c_i$；可达位置矩阵 $RL$

输出：带噪子节点集 $\mathcal{N}$

1. $sum = 0$;
2. 对于 $i$ 的每个子节点 $j$，执行
3. $c_j += \text{Lap}(1/\epsilon_i)$;
4. 如果 $c_j \ge \theta_{lv}$ 那么
5. $\mathcal{N} \leftarrow j$;
6. $sum += c_j$;
7. 结束判断
8. 如果 $sum \ge c_i$ 那么
9. 跳出循环;
10. 结束判断
11. 结束循环
12. 当 $sum < c_i$ 时
13. 随机选择一个时间 $t_j \in T$，且 $t_j > t_i$
14. 在时间 $(t_j - t_i)$ 内查找从 $l_i$ 出发的可达位置集 $\mathcal{L}_r$
15. 对于每个位置 $l_j \in \mathcal{L}_r$ 执行
16. $count = \text{Lap}(1/\epsilon_i) + 0$
17. 如果 $count \ge \theta_{lv}$ 那么
18. 添加 $e_{out} = t_j l_j$ 作为新的外向边；
19. 添加节点 $j$ 作为新的子节点；
20. $c_j = count$;
21. $sum += count$;
22. 结束判断
23. 如果 $sum \ge c_i$ 那么
24. 跳出循环;
25. 结束判断
26. 结束循环
27. 结束循环
28. 返回 $\mathcal{N}$；

> 解释：**BuildChildTree 的逻辑 (Procedure 2)**：
>
> - 这段代码描述了如何“生长”出一棵带噪声的树。它通过不断添加拉普拉斯噪声（`Lap(1/epsilon_i)`）来模糊真实的乘客流量信息，只有当计数值超过阈值 $\theta_{lv}$ 时，节点才会被保留。这有效过滤了由噪声引起的小概率错误路径。
>
> **可达位置矩阵 (Reachable location matrix $RL$)**：
>
> - 这是一个**交通领域特有的约束**。它不是纯粹的数据处理，而是结合了地理和时间限制（即在时间 $t_j - t_i$ 内，从 $l_i$ 到 $l_j$ 是否真的可行）。这能确保脱敏后的轨迹仍然是“交通逻辑合理”的，从而极大地提升了数据的可用性。
>
> **隐私保证的闭环**：
>
> - 论文最后再次强调了差分隐私的**组合性质**：
>   - **并行组合**：同一层级的节点不重叠，互不影响隐私预算。
>   - **序列组合**：同一条路径上的节点是串联的，因此必须满足“和 $\le \epsilon$”。这是证明该算法严格满足 $\epsilon$-差分隐私的逻辑基石。

1. **运行时间拆解 (Runtime Breakdown)**：
   - 论文通过实验证明了算法在处理 2.2 亿条记录的大规模数据集时非常快（<100s）。
   - **耗时瓶颈**：实验明确指出 75% 的时间消耗在“数据脱敏”（即添加拉普拉斯噪声和构建带噪前缀树）上。这符合差分隐私算法的预期，因为噪声生成和树遍历是核心计算开销。
2. **参数校准的必要性**：
   - 参数 $k$ 和 $b$ 决定了过滤阈值 $\theta_{lv}$。论文提醒读者，这两个参数并不是越大越好，存在一个最优平衡点。这对于实际应用中的算法调优非常重要。
3. **理性界 (Sanity Bound) 的标准性**：
   - 论文解释了为何选择 0.1% 作为理性界，因为这是差分隐私领域的“通用惯例”，这增加了论文结果在科学界的**可信度**和**可比性**。

### 全文总结

这篇论文的核心贡献可以概括为以下四个层面：

**从“经验”到“严谨”的范式转变**：论文摒弃了以往 DP 算法在树结构上简单平均分配预算的经验做法，首次从数学优化角度审视该问题。
**创新的数学建模**：
   - **查询概率模型**：巧妙地利用组合数学推导出轨迹节点被查询的概率，考虑到交通数据的物理约束（如无循环路径）。
   - **拉格朗日优化框架**：这是论文的灵魂，通过拉格朗日乘子法，在复杂的路径约束下找到了 $\epsilon_i$ 的全局最优分配解。
**理论指导下的高效算法**：提出的三个核心命题（关于兄弟节点、父子节点预算的数学关系）不仅证明了方案的合理性，还简化了算法复杂度，使得大规模轨迹数据（深圳地铁 2.8 亿记录）能在 160 秒内完成处理。
**实际应用的验证**：实验结果不仅表明了该方法在数据效用（准确性）上优于 SeqPT 等主流基准算法，还通过灵敏度分析证明了算法在不同参数下的鲁棒性。
