### 第二阶段：复现 Li's Algorithm (最关键的对比项)

Li 等人的算法是轨迹隐私保护的经典基准，其核心逻辑通常如下：

- **预算分配策略**：采用**均匀分配**。如果树高为 $H$，则每一层分配 $\epsilon / H$。这意味着每一层的所有节点共享相同的隐私强度，而不考虑节点本身的人数权重。
- **实现要点**：
  - 在 `UniformTrie` 类中，重写预算分配函数。
  - 确保其 `apply_noise_and_prune` 使用与论文一致的简单拉普拉斯噪声。
  - **翻译参考**：论文中提到 Li 的算法在处理大数据集时效用较低，这通常是因为均匀分配导致深层（长路径）节点分到的预算极少，被噪声彻底淹没。

```python
def calculate_relative_error(original_trie, sanitized_results, total_count):
    """
    original_trie: 原始数据的树对象（未加噪）
    sanitized_results: 处理后得到的路径列表 [{"path": "...", "count": ...}]
    total_count: 数据集总行程数
    """
    # 计算 sanity bound (s) = 0.1% of dataset size
    s = 0.001 * total_count
    
    errors = []
    # 获取原始的所有计数查询结果 (q(D))
    raw_data = {item['path']: item['count'] for item in original_trie.get_raw_data()}
    sanitized_data = {item['path']: item['count'] for item in sanitized_results}
    
    # 遍历所有路径计算误差
    all_paths = set(raw_data.keys()) | set(sanitized_data.keys())
    for path in all_paths:
        q_D = raw_data.get(path, 0)
        q_D_hat = sanitized_data.get(path, 0)
        
        # 按照公式：|q(D_hat) - q(D)| / max(q(D), s)
        error = abs(q_D_hat - q_D) / max(q_D, s)
        errors.append(error)
        
    return np.mean(errors) if errors else 0
```
