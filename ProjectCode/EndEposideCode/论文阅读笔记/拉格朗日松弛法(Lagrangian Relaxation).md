# 拉格朗日松弛法**(Lagrangian Relaxation)**

在优化问题中，我们经常遇到“目标函数”和“约束条件”。

- **直观理解：** 假设你想让一辆车跑得最快（目标），但你的油耗不能超过 **5L**（约束）。
- **松弛过程：** 我们把“不能超过 **5L**”这个生硬的约束去掉，把它变成一个“惩罚项”加到目标函数里。如果你多用了一点油，我就在你的速度评分里扣掉一定的分数。
- **在本文中：** 论文的目标是让查询误差最小，约束是“从根到叶子的总隐私预算必须等于 ϵ”。作者利用拉格朗日乘数 λ 构造了一个新函数，通过对 ϵi 求导令其为 **0**，推导出了最优的分配比例。

# **轨迹前缀树 (Trajectory Prefix Tree)**

这是一种专门存储路径数据的“字典树”（Trie）。

- **结构：** 根节点是起点，每个子节点代表轨迹的下一个位置。
- **特性：** 如果两个人的轨迹前段是一样的（比如都从图书馆走到饭堂），那他们在树的前几层共享同一个节点。
- **作用：** 在差分隐私中，我们不是给“某个人”加噪声，而是给“这个节点有多少人经过”这个**计数（Count）**加噪声。前缀树能很好地对海量轨迹进行统计聚合。
