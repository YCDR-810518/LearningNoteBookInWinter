# ai组末期考核项目代码文件夹
## 1. 代码文件夹结构
- data: 存放数据集的文件夹
- main.py: 主程序文件，包含数据预处理、模型训练和评估的代码
- model.py: 模型定义文件，包含模型架构和相关函数的代码
- utils.py: 工具函数文件，包含数据加载、评估指标计算等辅助
- requirements.txt: 依赖库文件，列出项目所需的相关包及其版本
## 2.项目代码需求
### 基本要求
* 复现 Figure 3~7
* 对 SeqPT、Li 方法以及本文算法，输出不同算法在每一层的 ε 分布对比图，以及每层 ε 的平均值+标准差曲
线。
* 在同一张图中并排展示 3 种方法的结果。
### 进阶要求
* 实现一个交互式“隐私预算—效用—结构”探索器。
  * 用户可调整参数：
    * epsilon （隐私预算）
    * height （树的高度）
    * k （阈值）
    * b （阈值）
    * query_samples （查询样本量）
* 参数调整后实时更新三类图表，并自动解释曲线变化的原因。
> Tips：注意输入数据规模，可仅导入部分数据集进行测试以提高工具运行效率
