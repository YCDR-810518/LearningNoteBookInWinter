# K-Means 聚类与 SVM 分类模型对比报告

## SVM 算法原理

支持向量机 (SVM) 是一种监督学习算法，用于分类和回归任务。它通过找到一个超平面来最大化类别之间的间隔，从而实现分类。

### 基本原理

对于二分类问题，SVM 试图找到一个超平面 w·x + b = 0，使得正类和负类的间隔最大化。间隔定义为 2 / ||w||。

优化目标是：

min 1/2 ||w||^2 + C Σ max(0, 1 - y_i (w·x_i + b))

其中 C 是正则化参数，控制间隔和错误分类的权衡。

### 核技巧

通过核函数，可以将数据映射到更高维空间，实现非线性分类。本实现使用线性核。

### 优化算法

使用梯度下降优化上述目标函数。

### 适用场景

SVM 适用于高维数据、小样本数据、非线性问题。优点：泛化能力强，鲁棒性好。缺点：计算复杂度高，不适合大规模数据。

## 模型对比

### K-Means vs SVM

- **监督 vs 无监督**：K-Means 是无监督聚类，SVM 是监督分类。
- **适用场景**：K-Means 用于探索性数据分析，SVM 用于预测。
- **优缺点**：K-Means 简单快速，但对初始值敏感；SVM 准确但计算慢。
- **在本数据集上的表现**：K-Means 纯度 0.8133，SVM 准确率 0.9333。

## 鸢尾花数据集特点

- **特征相关性**：花瓣长度和宽度高度相关，萼片相关性较低。
- **类别可分性**：山鸢尾与其他两类线性可分，变色鸢尾和维吉尼亚鸢尾有重叠。
- **数据分布**：150 个样本，4 个特征，3 个类别。
