# 红酒质量预测程序运行指南

## 项目简介
这是一个使用Python从头实现线性回归和逻辑回归的红酒质量预测项目。基于winequalityN数据集，预测红酒质量评分并分类好坏酒。使用uv进行依赖管理，所有输出和报告均为中文。

## 环境要求
- **Python版本**: >= 3.14
- **包管理器**: uv (安装方法: `pip install uv` 或从[官方文档](https://github.com/astral-sh/uv)安装)
- **操作系统**: 支持Windows、macOS、Linux

## 安装步骤
1. **获取项目代码**:
   - 下载或克隆项目到本地目录，例如 `D:\Documents\GitHub\LearningNoteBookInWinter\ProjectCode\LinerModel`

2. **进入项目目录**:
   ```
   cd D:\Documents\GitHub\LearningNoteBookInWinter\ProjectCode\LinerModel
   ```

3. **安装依赖**:
   ```
   uv sync
   ```
   此命令将安装所有必需的依赖包（numpy, pandas, kaggle）到虚拟环境。

## 运行程序
1. **执行主程序**:
   ```
   uv run python main.py
   ```

2. **预期输出**:
   - 终端将显示模型评估结果，例如：
     ```
     线性回归MSE: 0.4767842342340777
     逻辑回归准确率: 0.8638461538461538
     模型比较: 线性回归用于回归预测质量评分，逻辑回归用于二分类好坏酒。线性回归MSE较低表示预测准确，逻辑回归准确率高表示分类效果好。
     ```

3. **生成的文件**:
   - `codeReport.md`: 代码撰写过程和挑战解决方案报告。
   - `modelReport.md`: 模型异同分析和评估比较报告。

## 数据集说明
- **文件**: `winequalityN.csv`
- **内容**: 红酒质量数据集，包含特征如固定酸度、挥发性酸度等，以及目标变量quality（评分3-9）。
- **来源**: 项目已包含该文件，无需额外下载。

## 代码结构
- `classes.py`: 封装数据处理、线性回归、逻辑回归类及评估函数。
- `main.py`: 主程序，加载数据、训练模型、评估并生成报告。
- `pyproject.toml`: 项目配置和依赖声明。
- `uv.lock`: 依赖锁定文件，确保可重现安装。

## 故障排除
- **uv命令未找到**: 确保uv已安装并在PATH中。
- **Python版本错误**: 确认Python >= 3.14。
- **依赖安装失败**: 检查网络连接，或手动安装uv。
- **运行时错误**: 确保所有文件在同一目录，数据集文件存在。
- **模型性能问题**: 程序使用固定超参数，如需调整，可修改`classes.py`中的学习率和迭代次数。

## 注意事项
- 程序从头实现模型，不使用sklearn等库。
- 训练可能需要几秒钟，取决于硬件。
- 报告自动生成在项目根目录。
